# BACKLOG

1차 범위(관제 서버 중심 AMR FMS) 밖의 아이디어를 여기에 모은다.
범위 밖 요청은 구현 전에 먼저 이 문서에 기록한다.

## v2 후보

- **멀티로봇 교통정리 / 교착 회피** — 경로 예약, 교차점 통제. dispatch 정책이
  단일 로봇을 넘어설 때 필요.
- **충전 스테이션 자동 복귀 스케줄링** — 배터리 임계치 이벤트를 실제 복귀 작업으로 전환.
- **맵/노드 마스터 관리** — 노드(스테이션) 좌표·엣지 그래프를 DB로 관리.
  현재 좌표가 `control-service`(LocationRegistry)와 `robot-sim`(NodeMap) 양쪽에 **중복**돼
  있어 반드시 동기 유지 필요 → 서버 소유 맵을 로봇에 배포하거나 공유 계약으로 단일화.
- **Open-RMF 연동 검토** — 자체 관제 서버 vs 표준 미들웨어 경계 재정의.
- **작업 우선순위 SLA / 데드라인** — 우선순위 가중치에 마감시간 반영.
- **배정 ACK 타임아웃 / 고아 작업 복구** — ASSIGNED 상태로 일정 시간 STARTED 보고가
  없으면(로봇이 GOTO를 놓쳤거나 죽음) 작업을 재큐잉. 로밍 양보(현재 수정)로 흔한 레이스는
  막았지만, 분산 환경의 잔여 레이스에 대한 안전망이 필요.
- **로봇 원격 조작(teleop)·수동 개입 UI**
- **KPI/가동률 리포트** — 로봇별 가동시간, 작업 처리량, 실패율 집계.
