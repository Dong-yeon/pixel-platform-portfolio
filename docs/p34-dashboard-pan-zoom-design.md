# P34 — 대시보드 지도 확대/축소(Pan & Zoom)

> 상태: 설계 초안(경량) — 구조적 결정이 아니라 프론트엔드 기능 추가라 D1~Dn
> 형식 대신 스펙만 정리한다. P32/P33과 무관하게 독립적으로 착수 가능.
>
> 요청 원문: "마우스로 크게보고 작게 보고 할수 있으면 좋을것 같아."

## 배경

`UnifiedMap.tsx`는 SVG `viewBox` 기반이라(`<svg className="umap" viewBox={viewBox}
preserveAspectRatio="xMidYMid meet">`), 별도 차트/맵 라이브러리 없이 `viewBox` 값
조작만으로 줌·팬 구현이 가능하다. P32로 렉이 900개 안팎까지 늘어나는 걸 감안하면
이 기능은 구조 변경과 별개로 우선순위가 높다 — 전체를 한눈에 보면 렉 하나하나가
너무 작아진다.

## 스펙

- **줌(휠)**: `onWheel` 이벤트에서 `deltaY` 부호로 확대/축소 판단, `viewBox`의
  width·height를 비율로 축소/확대. 확대는 마우스 커서 위치를 중심으로(커서 아래
  지점이 고정된 채 확대되도록 `viewBox`의 x·y도 같이 보정).
- **팬(드래그)**: `onMouseDown`으로 드래그 시작점 기록, `onMouseMove`에서 이동한
  픽셀만큼 `viewBox`의 x·y를 반대로 이동. `onMouseUp`/`onMouseLeave`에서 종료.
- **줌 한계**: 최소(전체 보기, 현재 기본 `viewBox`)와 최대(렉 1~2개가 화면에 꽉
  차는 수준) 배율을 정해 그 범위 밖으로 안 나가게 clamp.
- **리셋 버튼**: 더블클릭 또는 별도 버튼으로 기본 `viewBox`로 복귀.
- **성능**: P32 이후 SVG 엘리먼트 수가 커지므로(900+ 렉), 줌 아웃 상태에서 화면 밖
  요소를 렌더링에서 제외하는 최적화도 같이 검토(필수는 아니고, 실측 후 느리면
  적용).

## 실행 단계

- [ ] 줌 최소/최대 배율 clamp
- [ ] 리셋 버튼(또는 더블클릭 리셋)
